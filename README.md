# Test-Genie-Logiciel-Via-ILEX
Test génie logiciel avec ILEX

## Description

Il s'agit d'un site d'information de test. Ce site affiche une page d'accueil simple avec le message "Hello World".

## Structure

- `www/index.html` - Page d'accueil du site

## Utilisation

Ouvrir le fichier `www/index.html` dans un navigateur web pour voir la page d'accueil.
